# 🌻 ENTERNA

Uma experiência web interativa criada para transformar sentimentos em uma experiência visual.

ENTERNA combina uma estética escura e elegante com tons dourados, efeitos de luz, flores e elementos interativos, criando uma atmosfera romântica e envolvente.

A experiência foi pensada para representar algo que começa pequeno e, aos poucos, floresce.

## ✨ Sobre o projeto

Este projeto foi desenvolvido como uma experiência de front-end, explorando a combinação entre design, animações, música e interatividade.

### 🌻 Funcionalidades

- 🌻 Botão interativo "Florescer"
- ✨ Efeitos visuais e partículas
- 🎵 Player de música
- 🌑 Interface escura com detalhes dourados
- 💫 Animações e interações
- 📱 Design responsivo

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript

## 🎵 Trilha sonora

A experiência utiliza a música:

> **Trevo (Tu) — ANAVITÓRIA**

A música foi escolhida para complementar a atmosfera romântica e delicada da experiência.

## 🎯 Objetivo

O objetivo do ENTERNA foi explorar como código, design e música podem se unir para criar uma experiência digital capaz de transmitir sentimentos.

Mais do que uma página, a proposta é criar uma pequena experiência para ser sentida.
